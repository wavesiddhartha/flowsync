Introduction

Real-time state sync, resolved mathematically.

FlowSync is an offline-first state synchronization engine. It links Python hubs to JS/React or Python clients, managing offline queueing and conflict merges automatically using Conflict-Free Replicated Data Types (CRDTs).

System Requirements

Environment Compatibility

  • Python: Version >= 3.10 required (uses native modern generic types and asyncio updates).
  • Node.js: Version >= 18.0 required.
  • Browsers: Modern standards with WebSocket & local storage support.

Tutorial

Step-by-Step Implementation

Follow this process to deploy a fully collaborative real-time feature in minutes.

Step 1 — Start the Hub

Start the central hub in Python and pre-register a collaborative counter stream.

import asyncio
from flowsync import FlowSyncHub

async def main():
    hub = FlowSyncHub(host="127.0.0.1", port=8765)
    hub.stream("counter:val", merge_rule="crdt-counter")
    await hub.start()

asyncio.run(main())
Step 2 — Connect Client (Vanilla)

Initialize the TypeScript client and update the stream value.

import { FlowSyncClient } from 'flowsync-client'

const client = new FlowSyncClient({
  url: 'ws://127.0.0.1:8765'
})
await client.connect()

// Push increment operation
await client.push('counter:val', {
  op: 'increment',
  amount: 1
})
Step 3 — React Hook Sync

Bind the stream state directly inside React components using the `useStream` hook.

import { useStream } from 'flowsync-client'

function CounterWidget() {
  const [val, push] = useStream('counter:val', 0)

  return (
    <button onClick={() => push({
      op: 'increment',
      amount: 1
    } as any)}>
      Count: {val}
    </button>
  )
}
